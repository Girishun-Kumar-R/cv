# Sample deliverables (fictional data)

Generated by finance-analyst plugin v0.3.0 (spec 1.3.0) from bundled synthetic data only.
No customer data is included.

- `half-year-sample/` — `examples/sample-sme`, comprehensive depth: report (PDF, HTML, Markdown), Excel dashboard
  with live formulas, the independent formula audit (`xlsx_audit.json`: own evaluator + LibreOffice) and the
  verification record.
- `q4-monthly-january-mismatch/` — the regression fixture from `tests/test_hardening.py` with January salaries
  booked in the month but not in the quarter total. The roll-up check `ai_period_rollup` raises a critical
  issue naming the account and month, the monthly table is withheld, and the status line says so.
